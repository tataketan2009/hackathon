# 15 Independent Design Style Websites

Each folder contains a separate standalone website (`index.html`) with its own styling and page layout.

## Run
1. Extract the ZIP.
2. Open any style folder.
3. Double-click `index.html` to open that website in your browser.

No Node.js, framework, database, or internet connection required.

- `y2k-design/` — Y2K Design
- `retro-design/` — Retro Design
- `cyberpunk/` — Cyberpunk
- `editorial-design/` — Editorial Design

## Customize
Each page is self-contained. Open `index.html` in a code editor and adjust the CSS variables at the top of the `:root` declaration, then edit the content in the HTML.
