# Form / Function — 15 Web Design Styles

A responsive, single-file gallery for exploring 15 interface design styles.

## Run it
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Search/filter styles and click **Explore** on any card.

No Node.js, frameworks, database, or internet connection required.

## Included styles
1. Minimalism
2. Maximalism
3. Glassmorphism
4. Neumorphism
5. Claymorphism
6. Brutalism
7. Neo-Brutalism
8. Skeuomorphism
9. Flat Design
10. Material Design
11. Bento UI
12. Y2K Design
13. Retro Design
14. Cyberpunk
15. Editorial Design

Edit the CSS in `index.html` to customize colors, spacing, and previews.
